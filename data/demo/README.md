# Demo Data

This directory contains a synthetic proteomics dataset generated by `scripts/generate_demo_data.py`.

## Experiment Background

This dataset simulates a **DIA plasma proteomics study** investigating metabolic disease in a two-group (Case / Control) cohort, with samples collected across multiple mass-spectrometry acquisition runs (plates). The data are modelled on real-world multi-plate Spectronaut exports.

## Study Design

| Property | Details |
|----------|---------|
| Biological samples | 160 (80 Case / 80 Control) |
| Plates | 4 plates × 40 biological samples |
| QC pooled controls | 12 (3 identical replicates per plate) |
| Proteins | 2 000 |
| Covariates | Sex (Male / Female, balanced); Age (40–65 yr, continuous) |
| Missing values | ~37 % biological, ~3 % QC (MNAR — low-abundance proteins more likely absent) |

## Sample Metadata (demo_metadata.csv)

| Column | Description |
|--------|-------------|
| `sample_id` | Unique sample identifier (row index) |
| `plate` | Plate ID (Plate_01 – Plate_04) |
| `group` | Biological group: Case, Control, or QC |
| `subject_id` | Subject number (NaN for QC samples) |
| `sex` | Male / Female (NaN for QC) |
| `age` | Age in years (NaN for QC) |
| `is_qc` | Boolean — True for pooled QC controls |

## Technical Considerations

- **Pooled QC controls**: three injections of the same reference pool per plate. Because they share identical biology, any variation *within* a plate reflects instrument/injection noise (intra-plate CV), while variation *across* plates reflects batch effects (inter-plate CV). Use these to assess and benchmark batch correction.
- **Batch effects**: each plate carries a systematic intensity shift (added during data generation). These should be clearly visible in PCA before correction and substantially reduced after ComBat or plate-median correction.
- **MNAR missing values**: proteins are absent more often when their true abundance is low. This is realistic and must be handled carefully — imputation for visualisation only, not for downstream statistics.
- **Outlier samples**: the dataset contains planted technical outlier samples, each with a distinct failure mode (e.g. failed injection, intensity shift, contamination). Students are expected to discover and characterise these through the multi-method detection pipeline.
