# Demo Data

This directory contains a synthetic proteomics dataset generated by `scripts/generate_demo_data.py`.

## Experiment Background

This dataset simulates a **longitudinal DIA plasma proteomics study** investigating metabolic
disease in a two-group (Case / Control) cohort measured at three time points.
The data are modelled on real-world multi-plate Spectronaut exports, including realistic
batch effects, MNAR missing values, and planted technical outliers.

---

## Study Design

| Property | Details |
|----------|---------|
| Biological samples | 480 (160 subjects × 3 time points) |
| Subjects | 160 (80 Case / 80 Control) |
| Time points | 3 per subject: T00 (baseline), T01, T02 |
| Plates | 4 plates × 120 biological samples each |
| QC pooled controls | 12 (3 identical replicates per plate) |
| Proteins | 2 000 (log2 LFQ intensities) |
| Covariates | Sex (Male / Female, balanced within each group); Age (40–65 yr, continuous) |
| Missing values | ~37 % biological, ~3 % QC (MNAR — low-abundance proteins more likely absent) |

### Latin square plate design

Sex and group are balanced within each condition, and the plate assignment follows a Latin
square so that **no plate is confounded with time point, group, or sex**:

```
Subject group A (40 subjects): T00→Plate1, T01→Plate2, T02→Plate3
Subject group B (40 subjects): T00→Plate2, T01→Plate3, T02→Plate4
Subject group C (40 subjects): T00→Plate3, T01→Plate4, T02→Plate1
Subject group D (40 subjects): T00→Plate4, T01→Plate1, T02→Plate2
```

Each plate receives 40×T00 + 40×T01 + 40×T02 = 120 biological samples + 3 QC = 123 samples/plate.

## Sample Metadata (demo_metadata.csv)

| Column | Description |
|--------|-------------|
| `sample_id` | Unique sample identifier (row index) |
| `subject_id` | Subject number (shared across 3 time points; NaN for QC) |
| `timepoint` | T00, T01, or T02 (NaN for QC) |
| `plate` | Plate ID: Plate_01 – Plate_04 |
| `group` | Biological group: Case, Control, or QC |
| `sex` | Male / Female (NaN for QC) |
| `age` | Age in years at enrolment (NaN for QC) |
| `is_qc` | Boolean — True for pooled QC controls |

## Technical Considerations for Students

### Batch effects
Each plate carries a **protein-specific** systematic intensity shift (not just a global offset).
This is important: a uniform shift would be removed by median normalisation, but protein-specific
effects survive normalisation and are visible in PCA as clustering by plate.
Students can observe this in PC1/PC2 before correction and confirm batch removal after ComBat.

### Pooled QC controls
Three injections of the same reference pool per plate. Because all 12 QC samples are
identical biology, any variation **within a plate** (3 replicates) reflects pure instrument
noise (intra-plate CV ≈ 3–5%), while variation **across plates** reflects the batch effect
(inter-plate CV >> intra-plate before correction, ≈ intra-plate after correction).

### Longitudinal structure
Each subject contributes 3 time points. Within-subject protein profiles are highly correlated
(~80 % after imputation) because each subject has a personal "fingerprint" that is stable
across time. Students can observe this as time-point clustering in t-SNE.

### Hidden outlier samples
Four technical outlier samples are planted in the data, one per plate, each with a distinct
failure mode. Students are expected to discover and characterise them through the
multi-method outlier detection pipeline.

### MNAR missing values
Missing values are more likely for low-abundance proteins. KNN imputation is used only for
visualisation (PCA, t-SNE). All statistical analyses should use the original normalised
matrix that preserves real missingness.
