# Demo Data

This directory contains a synthetic proteomics dataset generated by `scripts/generate_demo_data.py`.

## Files

| File | Description |
|------|-------------|
| `demo_proteomics.parquet` | Protein intensity matrix (2000 proteins × 160 samples) |
| `demo_metadata.csv` | Sample metadata: plate, group, subject_id |

## Known properties (for exercises)

- **4 hidden outlier samples** with different failure modes
- **Batch effects**: plates 2–4 have intensity shifts of +0.35, −0.25, +0.50 log2 units
- **Differential expression**: 20 % of proteins have |log2FC| 0.3–0.8 between Case and Control
- **Missing rate**: ~37 % overall (structured by protein abundance)

To regenerate: `python scripts/generate_demo_data.py`
